# 智慧物流与配送模拟系统

## Lab01

#### 一、功能要求

**1.**创建并显示包裹

​	（1）能够根据输入创建包裹，并显示单个包裹的完整信息。包裹信息至少包括<u>编号、寄件人、收件人、重量和当前状态</u>。

​	（2）能够连续创建不少于3个包裹， 并以列表形式显示当前全部包裹。新包裹的状态统一为**“待入站”**

**2.**查询包裹

​	（1）能够根据包裹编号查看指定包裹，并能够查看全部包裹。

​	（2）查询不存在的编号时应给出提示，不得显示其他包裹的信息。

**3.**基础数据校验

​	（1）包裹编号不能为空且不能重复，重量必须大于0，寄件人和收件人不能为空。

​	（2）输入不符合要求时应拒绝创建，并明确说明失败原因。
